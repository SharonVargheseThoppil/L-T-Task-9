# Task 9: Docker Fundamentals and Container Lifecycle Management

## Objective

To understand Docker architecture and manage containerized applications.

## Tools Used

- Docker Desktop
- Docker CLI
- Visual Studio Code
- PowerShell
- Python

## Project Description

This project demonstrates fundamental Docker operations including image creation, container management, container lifecycle operations, networking, and persistent storage using Docker volumes.

## Application

The Python application displays information about the runtime environment and periodically generates heartbeat messages.

## Docker Image

The application is packaged into a Docker image named:

task9-docker-app

## Container Operations

The following operations were performed:

- Build Docker image
- Run container
- List containers
- View container logs
- Inspect container
- Stop container
- Start container
- Restart container
- Pause container
- Unpause container
- Execute commands inside container
- Remove container

## Networking

A custom Docker network named `task9-network` was created and used by the application container.

## Storage

A Docker volume named `task9-volume` was created to demonstrate persistent storage.

## Result

The Python application was successfully containerized and executed using Docker. Docker image, container lifecycle, networking, and persistent storage concepts were successfully demonstrated.

## Conclusion

This practical provided hands-on understanding of Docker fundamentals and container lifecycle management.
